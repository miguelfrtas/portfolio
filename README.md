## ✨ Funcionalidades

- **Design responsivo** — adapta para mobile, tablet e desktop
- **Cursor customizado** animado com efeito ring seguidor via `requestAnimationFrame`
- **Seção de habilidades** com tabs interativas e pílula deslizante animada por CSS + JS
- **Modais de experiência** com animação de entrada/saída e bloqueio de scroll
- **Integração com GitHub API** — exibe contribution graph, total de commits, streak e repos ao vivo
- **Scroll reveal** com `IntersectionObserver` — animações escalonadas ao rolar
- **Navegação âncora** com smooth scroll, flash de seção e scroll spy no nav
- **Performance** — `will-change`, `contain`, `backdrop-filter` isolado em pseudo-elemento, sem `box-shadow` em hovers

```
└── index.html   # tudo em um único arquivo (HTML + CSS + JS)
```

---

## 🚀 Como rodar localmente

```bash
# clone o repositório
git clone https://github.com/miguelrfreitas/portfolio.git

# abra o arquivo no navegador
cd portfolio
open index.html   # macOS
# ou arraste o index.html para o navegador
```

> Não precisa de `npm install`, servidor local ou qualquer dependência — abre direto no browser.

---

## 📡 Deploy

O projeto está hospedado via **GitHub Pages**. Qualquer push na branch `main` atualiza automaticamente.

Para hospedar o seu próprio fork:
1. Vá em **Settings → Pages**
2. Source: `Deploy from a branch` → `main` → `/ (root)`
3. Sua URL será `https://seu-usuario.github.io/portfolio`
